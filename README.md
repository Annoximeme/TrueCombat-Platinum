# TrueCombat: Platinum

Native 64-bit Windows rebuild of TrueCombat: Elite with DirectX 12 rendering,
an OpenGL Safe start option and optional NVIDIA DLSS/DLAA.

Developed by RaziC* — Team Terminus.

## Download

Get the latest version from [Releases](../../releases/latest). Download the
`TrueCombat-Platinum-…-Windows-x64.zip`, extract the whole folder to a
writable location (for example Documents or Games) and run
`TrueCombatPlatinum.exe`.

The launcher checks this page for new versions and can update itself from the
update bar above the PLAY button. Your settings, profile and server data are
kept during an update.

## Status

This is an experimental native sandbox, not complete TC:E gameplay. Recoil,
spread, penetration, leaning and the original round rules are still being
rebuilt. It has been tested on one PC over local connections; separate PCs and
internet play are not verified yet. Everyone in a match must use the same
version.

Each release includes its patch notes, a READ-ME and the corresponding source
code (`source/native-sandbox-source.zip`). Original game data and artwork keep
their original terms; see the `licenses` folder in the download.
