    Meedoen op een server

    • Open de launcher en ga naar Servers. Daar staan publieke servers, je favorieten en recente servers.
    • Of kopieer een adres van deze pagina, plak het in het adresvak en druk op PLAY.
    • Je hebt dezelfde spelversie nodig als de server. De launcher werkt zichzelf bij als er een nieuwe versie is.

    Je server in de lijst

    • Druk in de launcher op Host a server en zet List publicly aan.
    • Sta UDP-poort 27971 (of de poort die je koos) toe in Windows Firewall en stuur hem door in je router.
    • Je server meldt zich om de paar minuten bij de masterserver, en verschijnt daarna binnen een minuut hier.
