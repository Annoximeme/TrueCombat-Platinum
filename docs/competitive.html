Competitive

Match mode

Clan matches the way TC:E was meant to be played: ready-up, a knife round for sides, half-time, tactical timeouts and a final score. Built into every Platinum server since 0.32.

Join match nights on Discord Run a match Leaderboards
How a match runs

From warmup to final score

  1. Warmup

    Free play with respawns. Pick any side, uneven teams are fine. Type ready in the console when your team is set. The match starts the moment every player is ready.

  2. Knife round

    One round, knives only, no respawns, two minutes on the clock. Guns, grenades, the bomb and the flags stay out of play. A draw keeps the sides as they are.

  3. Side pick

    Anyone on the winning team types stay or swap. No answer within the time limit means stay.

  4. Live

    Twelve rounds in the round modes, or two 20-minute halves in Team Deathmatch and Flag Capture. Teams are locked, and warmup kills are wiped from the scoreboard and the leaderboards.

  5. Half-time

    Halfway through, the teams swap sides. Scores, clan names and remaining timeouts travel with the players.

  6. Final score

    A team that can no longer be caught wins on the spot, 7 to 2 in a 12-round match for example. The result stays on screen, then the server returns to warmup or moves on to the next map.

Timeouts

Everything stops. Nothing is lost.

Each team gets two tactical timeouts of 60 seconds by default, and admins can pause for as long as they need. During a pause the whole match freezes: players, grenades in flight, the round clock, the bomb timer, dropped backpacks, reloads and respawn waves all keep exactly the time they had left. Play resumes after a five-second countdown.

Player commands

ready / notreadySet your ready state in warmup
timeoutCall a tactical timeout for your team
unpauseEnd your own team's timeout early
stay / swapKnife round winners choose their side
matchinfoShow the match state

Admin commands

match on / offSwitch match mode on or off
match startStart now, without waiting for ready
match pause / unpauseAdmin pause, no time limit
match name r|b <name>Set a clan name for a team
match team <player> r|bMove a player to a team
match restartBack to warmup with scores cleared
Run a match

Host your own clan match

  1. Host a server from the launcher in a team mode: Team Elimination, Bomb, Flag Capture or Team Deathmatch.
  2. In the server console, or over rcon, type match on. Everyone drops back to warmup.
  3. Name the teams with match name r and match name b, then let both sides ready up.
  4. Keep sv_mapRotationTime 0 so the server never changes map in the middle of a match.

Ranked servers report every completed match to the leaderboards. Warmup and knife round kills never count.

Match settings

g_competitive1 turns match mode on at map start
g_matchRoundsRounds per match, even number (12 by default)
g_matchKnifeRoundKnife round for sides (on)
g_matchMinPlayersPlayers needed per team (1)
g_matchTimeoutsTimeouts per team (2)
g_matchTimeoutTimeSeconds per timeout (60)
g_matchHalftimeHalf-time in seconds (30)
g_matchEndAction0 back to warmup, 1 next map and vote
