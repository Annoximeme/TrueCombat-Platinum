Download TrueCombat: Platinum

The complete game for Windows 10 and 11, free of charge. One small installer sets up the game and the launcher, then keeps both current.

Download v0.36.0Windows installer · 9 MB · 13 Nov 2026 All releases
  1. Download the installer. It is a small file, so it never grows with new releases.
  2. Choose where to install. Keep the game and the launcher together, or give each its own folder.
  3. Let the launcher do the rest. It downloads the game, verifies every file and keeps it current. Updates only fetch the files that changed.

Already installed? Open the launcher. It updates itself and the game.

What you need

System
Windows 10 or 11, 64-bit
Graphics
A DirectX 12 card. Older cards can use Safe start (OpenGL).
DLSS / DLAA
Optional, NVIDIA RTX cards
Disk
About 2.3 GB free space
Online
A connection for the download and for online play. Bot matches work offline.
Price
Free. No store, no paid unlocks.
In the download

Everything you need to play

The full game

Six original maps, all 27 guns and seven game modes. There is nothing else to install: no copy of TC:E, no Enemy Territory.

The launcher

Server browser, one-click hosting, graphics presets and a Safe start button for older hardware, all in one window.

Signed updates

The launcher checks for new versions, fetches only the files that changed and installs only updates signed by Team Terminus.

First match

From install to in-game

  1. Pick a name

    Open TrueCombat: Platinum and type your player name. It is saved for next time.

  2. Join a server

    The Servers tab lists every public server. Official #2 always has a match running, and Official #1 counts towards the leaderboards.

  3. Or warm up first

    Practice offline with bots starts a match in one click. The beginner's guide covers the controls.

Playing on more than one PC? A free account keeps your rank, stats and name with you. You sign in with Discord, and it is entirely optional.

Help

If something stops you

Windows shows a SmartScreen notice

Windows shows this for installers it has not seen often yet. Choose More info, then Run anyway. From then on the launcher verifies every update itself.

DirectX 12 won't start

Press Safe start in the launcher. It runs the game on OpenGL in a 1280 × 720 window and leaves your normal settings alone.

My server runs an older version

Everyone in a match needs the same version. The launcher can stay on an older release for as long as your community needs it, and return to the latest whenever you like.

I need a hand

Ask in the TrueCombat: Platinum Discord. The team and the community answer there every day.
