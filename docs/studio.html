Our story

Where it started

New where it should be. Untouched where it matters.

TrueCombat: Elite is where we learned the game. One life per round, real weapons, and clan matches decided by a single well-held corner. Years later it still runs as a 32-bit mod on an engine from 2003.

Team Terminus was formed to change that. TrueCombat: Platinum rebuilds the game as a native 64-bit Windows title with a DirectX 12 renderer, and every map, weapon value and HUD element is checked against the original before it ships.

How we build

Every change takes the same route

Nothing reaches your launcher on a hunch. Each feature, fix and weapon value goes through four steps before it ships.

  1. 01

    Reference

    Start from the original TC:E game data and the original game itself, never from memory.

  2. 02

    Rebuild

    Write it natively for 64-bit Windows, on DirectX 12 with OpenGL as the safe fallback.

  3. 03

    Verify

    Automated checks compare the result with the original on both renderers, then the full regression runs.

  4. 04

    Ship

    Signed updates through the launcher, patch notes on day one, and a devlog on how it was made.

What drives us

Three rules we build by

  1. Faithful first

    Movement speeds, weapon values and HUD layout come from the original game data, not from memory.

  2. Built for today

    Native 64-bit, DirectX 12, signed updates and a launcher that hosts a server in one click.

  3. Free for everyone

    No price tag, no forced accounts and no tracking. The game belongs to its players.
