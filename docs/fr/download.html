Télécharger TrueCombat: Platinum

Le jeu complet pour Windows 10 et 11, gratuitement. Un petit installeur met en place le jeu et le launcher, puis les maintient à jour.

Télécharger v0.35.0Installeur Windows · 9 MB · 12 nov. 2026 Toutes les versions
  1. Téléchargez l'installeur. C'est un petit fichier, qui ne grossit pas avec les nouvelles versions.
  2. Choisissez l'emplacement. Gardez le jeu et le launcher ensemble, ou donnez à chacun son dossier.
  3. Laissez le launcher faire le reste. Il télécharge le jeu, vérifie chaque fichier et le maintient à jour. Les mises à jour ne récupèrent que les fichiers modifiés.

Déjà installé ? Ouvrez le launcher. Il se met à jour, et le jeu avec lui.

Configuration requise

Système
Windows 10 ou 11, 64 bits
Carte graphique
Une carte DirectX 12. Les cartes plus anciennes peuvent utiliser Safe start (OpenGL).
DLSS / DLAA
En option, cartes NVIDIA RTX
Disque
Environ 2,3 Go d'espace libre
Connexion
Une connexion pour le téléchargement et le jeu en ligne. Les matchs contre les bots fonctionnent hors ligne.
Prix
Gratuit. Pas de boutique, pas de déblocages payants.
Dans le téléchargement

Tout ce qu'il faut pour jouer

Le jeu complet

Six maps d'origine, les 27 armes à feu et sept modes de jeu. Rien d'autre à installer : ni TC:E, ni Enemy Territory.

Le launcher

Navigateur de serveurs, hébergement en un clic, préréglages graphiques et bouton Safe start pour le matériel plus ancien, le tout dans une seule fenêtre.

Mises à jour signées

Le launcher cherche les nouvelles versions, ne récupère que les fichiers modifiés et n'installe que les mises à jour signées par Team Terminus.

Premier match

De l'installation au jeu

  1. Choisissez un nom

    Ouvrez TrueCombat: Platinum et saisissez votre nom de joueur. Il est enregistré pour la prochaine fois.

  2. Rejoignez un serveur

    L'onglet Servers liste tous les serveurs publics. Un match tourne en permanence sur Official #2, et Official #1 compte pour les classements.

  3. Ou échauffez-vous d'abord

    Practice offline with bots lance un match en un clic. Le guide du débutant présente les commandes.

Aide

Si quelque chose vous bloque

Windows affiche un avertissement SmartScreen

Windows l'affiche pour les installeurs qu'il n'a pas encore souvent rencontrés. Choisissez Informations complémentaires, puis Exécuter quand même. Ensuite, le launcher vérifie lui-même chaque mise à jour.

DirectX 12 ne démarre pas

Appuyez sur Safe start dans le launcher. Le jeu tourne alors en OpenGL dans une fenêtre de 1280 × 720, sans toucher à vos réglages habituels.

Mon serveur tourne sur une version antérieure

Tous les joueurs d'un match doivent avoir la même version. Le launcher peut rester sur une version antérieure aussi longtemps que votre communauté en a besoin, et revenir à la dernière quand vous voulez.

J'ai besoin d'un coup de main

Posez votre question sur le Discord de TrueCombat: Platinum. L'équipe et la communauté y répondent chaque jour.
