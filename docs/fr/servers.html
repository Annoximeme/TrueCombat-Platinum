    Rejoindre

    Rejoindre un serveur

    • Ouvrez le launcher et allez dans Servers. Les serveurs publics, vos favoris et vos serveurs récents y sont listés.
    • Ou copiez une adresse depuis cette page, collez-la dans le champ d'adresse et appuyez sur PLAY.
    • Il vous faut la même version du jeu que le serveur. Le launcher se met à jour tout seul quand une nouvelle version sort.

    Faire référencer votre serveur

    • Appuyez sur Host a server dans le launcher et activez List publicly.
    • Autorisez le port UDP 27971 (ou celui que vous avez choisi) dans le pare-feu Windows et redirigez-le sur votre routeur.
    • Votre serveur signale au serveur maître qu'il est en ligne toutes les quelques minutes, et apparaît ici dans la minute qui suit.
