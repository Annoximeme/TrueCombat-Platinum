Join a server

  • Open the launcher and go to Servers. Public servers, your favorites and recent servers are listed there.
  • Or copy an address from this page, paste it into the address box and press PLAY.
  • You need the same game version as the server. The launcher updates itself when a new version is out.

Get your server listed

  • Press Host a server in the launcher and switch on List publicly.
  • Allow UDP port 27971 (or the port you picked) through Windows Firewall and forward it on your router.
  • Your server tells the master server it's online every few minutes, and shows up here within a minute after that.
