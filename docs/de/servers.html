      Einem Server beitreten

      • Öffne den Launcher und geh auf Servers. Dort stehen öffentliche Server, deine Favoriten und zuletzt besuchte Server.
      • Oder kopiere eine Adresse von dieser Seite, füg sie ins Adressfeld ein und drück PLAY.
      • Du brauchst dieselbe Spielversion wie der Server. Der Launcher aktualisiert sich selbst, sobald eine neue Version erscheint.

      Deinen Server listen lassen

      • Drück im Launcher auf Host a server und schalte List publicly ein.
      • Gib den UDP-Port 27971 (oder den von dir gewählten Port) in der Windows-Firewall frei und leite ihn im Router weiter.
      • Dein Server meldet dem Master-Server alle paar Minuten, dass er online ist, und erscheint danach innerhalb einer Minute hier.
